SupaBase Overview:
    Open-source PostgreSQL-based backend with built-in authentication & storage
    Provides real-time data syncing and easy API generation
    Ideal for user management, recipe storage, and real-time updates

    Open-source backend-as-a-service built on PostgreSQL
    Provides authentication, database, storage, and real-time capabilities without managing infrastructure
    Direct alternative to Firebase but uses SQL instead of NoSQL
    Built-in REST & GraphQL APIs to interact with the database easily

What SupaBase Does
    Authentication → Handles user sign-ups, logins, and role-based access
    Database → Uses PostgreSQL for structured and scalable data storage
    Storage → Manages file uploads (images, documents, etc)
    Real-time Updates → Syncs data changes instantly across clients
    Edge Functions → Serverless functions for backend logic (similar to AWS Lambda)



Flask Overview
    Lightweight Python web framework for building APIs
    Great for handling backend logic, routing, and database integration
    Supports SQLAlchemy for database management and Marshmallow for data serialization
    Ideal for custom business logic and integrating with other APIs (OpenAI, Spoonacular, etc)

What Flask Does
    Handles API requests (GET, POST, PUT, DELETE)
    Manages user authentication (JWT, OAuth)
    Processes external API calls (eg, fetching recipes from Spoonacular)
    Interacts with a database (SQLAlchemy for PostgreSQL, MongoDB, or SQLite)
