Vitest:
    - Unit testing framework for Vite-based React projects
    - Supports mocking with vi.fn()
    - Run tests in terminal: npm run test
    - Run coverage: npm run coverage
    - Optional UI mode: npx vitest --ui

Tests Included

recipeService.js Tests
generateRecipeFromText()
    - Why: Ensure that a valid prompt returns a matching recipe string
    - How:
        1. Mock the entire recipeService module using vi.mock()
        2. Return a resolved Promise with known recipe string
        3. Call generateRecipeFromText(systemPrompt, prompt)
        4. Use expect(result).toContain("Tofu Stir Fry")

profileUtils.js Tests

addItemToList()
    - Why: Check that a new item is added to the array
    - How:
        1. Pass ["Tofu"] and "Mushrooms" to addItemToList
        2. Expect result to equal ["Tofu", "Mushrooms"]

addItemToList() with empty input
    - Why: Ensure whitespace-only strings are ignored
    - How:
        1. Pass ["Lentils"] and "   " to addItemToList
        2. Expect result to equal ["Lentils"]

removeItemFromList()
    - Why: Ensure an item is removed by index
    - How:
        1. Pass ["Eggs", "Spinach", "Cheese"] and index 1 to removeItemFromList
        2. Expect result to equal ["Eggs", "Cheese"]
