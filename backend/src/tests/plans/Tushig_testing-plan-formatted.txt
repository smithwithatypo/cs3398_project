receiptScanningController.js Tests:
    scanReceipt(req, res)
        - Why: I want to test the controller returns food items after successful scanning
        - How: 
            1. Mock request with file (originalname, buffer)
            2. Mock response object (status, json)
            3. Mock service to return food items ["apples", "milk", "bread"]
            4. Call scanReceipt(req, res)
            5. Verify response status is 200 and json data contains food items

    scanReceipt(req, res)
        - Why: I want to test the controller handles missing files correctly
        - How:
            1. Mock request with null file
            2. Mock response object (status, json)
            3. Call scanReceipt(req, res)
            4. Verify response status is 400 and json contains appropriate error message

    scanReceipt(req, res)
        - Why: I want to test the controller handles service errors appropriately
        - How:
            1. Mock request with file
            2. Mock response object (status, json)
            3. Mock service to reject with error "Could not find any food items"
            4. Call scanReceipt(req, res)
            5. Verify response status is 500 and error message is user-friendly

Mocking Strategy:
    - OpenAI module is mocked to avoid actual API calls
    - vi.mock('openai') is called before importing service
    - Service layer is mocked for different test scenarios
    - Request/Response objects are mocked to simulate Express behavior
