### Updated receiptScanning.test.js Tests:

#### 1. Controller Test: Successful Scanning
- **Why**: To test the controller returns food items after successful scanning
- **How**: 
    1. Mock OpenAI, fs, path, and os modules before importing code under test
    2. Mock request with file (originalname, buffer)
    3. Mock response object (status, json)
    4. Mock service to return food items ["apples", "milk", "bread"]
    5. Call scanReceipt(req, res)
    6. Verify response status is 200 and json data contains food items
    7. Verify service was called with correct parameters

#### 2. Controller Test: Missing File Error
- **Why**: To test the controller handles missing files correctly
- **How**:
    1. Mock request with null file
    2. Mock response object (status, json)
    3. Call scanReceipt(req, res)
    4. Verify response status is 400 and json contains appropriate error message
    5. Verify service was not called

#### 3. Controller Test: No Food Items Error
- **Why**: To test the controller handles service errors about no food items
- **How**:
    1. Mock request with file
    2. Mock response object (status, json)
    3. Mock service to reject with error "Could not find any food items"
    4. Call scanReceipt(req, res)
    5. Verify response status is 500 and error message is user-friendly

### Mocking Strategy:
- OpenAI module is mocked to avoid actual API calls
- fs, path, and os modules are mocked to avoid file system operations
- vi.mock() is called before importing the modules to ensure mocks are applied
- Service layer is mocked for different test scenarios
- Request/Response objects are mocked to simulate Express behavior

### Running Tests:
- Run specific test file: `npx vitest run src/tests/receiptScanning.test.js`
- Run with UI: `npx vitest --ui`
- Run all tests: `npx vitest run`
- Run with coverage: `npx vitest run --coverage`

### Test Output:
- Terminal output shows test results directly
- UI view available with `npx vitest --ui` at http://localhost:51204/__vitest__/
- Coverage reports in "coverage" directory (open coverage/index.html in browser)
- Save output to file: `npx vitest run src/tests/receiptScanning.test.js > test-results.txt`
